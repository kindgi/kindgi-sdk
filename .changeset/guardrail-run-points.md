**A guardrail says where in the agent's turn it runs: `at`.** `'before-tool'` judges a call the model asked for, before it runs and before any approval is asked; `'after-tool'` a call's result, before the model sees it; `'model-step'` each model reply, before any of its calls runs; and `'final-answer'`, the default, the answer that would be stored. `sees: 'conversation'` gives the check the conversation's earlier turns too (`trace.earlier`), and `scope.tools` limits a guardrail at a tool point to the tools it names (a trailing `*` matches every id with that prefix). A check says where it can run with `defineCheck({ points })`; one that names none runs at the final answer only, as every check does today. A guardrail at a point its check doesn't run at is refused by `validateGuardrail`, the pack indexer, the deploy route, and the register route when it names a built-in check (`422 guardrail-config-invalid`, the problem at `/at`); for a pack check, the register route leaves it to the runtime's `GuardrailConfigCheck`, whose doc now says so. A pack check whose index lists no points runs at the final answer only. `validateGuardrail` and `validateGuardrailSpec` also refuse one that asks a point for what it can't do, so registering answers `400 validation-failed` and deploying `deployment-validation-failed`: `'escalate'` and `'compensate'` stay at the final answer, where they're recorded as today, and `scope.tools` is for the tool points. `scope.tools` names one or more tools, with a `*` only at the end. The pack indexer refuses an `at` or `sees` it doesn't know, a malformed `scope.tools` or `points`, a point the pack's check doesn't run at, and what a point can't do, with the deploy's paths and words (`guardrail <id>: /action/on-violation: "escalate" is recorded at the final answer only, not at "before-tool"`), so a pack that builds doesn't fail its deploy for them; a built-in check at a point it doesn't run at is refused at deploy. The built-in checks: `must-cite` and `required-substring` run at the final answer; `never-call-tool`, `max-tool-calls` and `tool-order` before a tool call too, judging that call against the turn's earlier calls; `output-matches` and `forbidden-substring` on each reply and each call's result too. The pack index carries `at`, `sees` and the pack check's `checkPoints`.
