**A pack image without build steps installs production dependencies only.** `kindgi build` used to install every dependency, dev ones included, then prune to production, so an app's dev tools (test runners, bundlers, doc generators) were downloaded for every image build, even when nothing used them. Now, when `image` has no build steps, the install takes production dependencies only: `pnpm install --prod` (in a workspace, with the same filter), `npm ci --omit=dev`, and `yarn install --production` for Yarn 1, with no prune after. With build steps (`prisma()`'s `prisma generate`), whose tools can be dev dependencies, the install still takes dev dependencies too and prunes them after the steps. Yarn 2 or later keeps the full install and the prune as well, because its production install (`yarn workspaces focus --production`) installs a dependency missing from `yarn.lock` instead of failing, even with `enableImmutableInstalls` on (it takes no `--immutable`). The build output says which (`✓ Install: production dependencies only`, or why dev dependencies too), and so does a comment in the Containerfile. The final image is production-only either way.
