`@kindgi/cli`, the `kindgi` command, now lives in this repository: create a pack (`kindgi init`), run it on your machine against the Kindgi runtime image (`kindgi dev`), build, sign and deploy it, and work with a running Kindgi API from the terminal. It depends only on `@kindgi/*` packages and joins the fixed version group. The README is rewritten for how the CLI works today.
