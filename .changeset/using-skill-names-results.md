**The kindgi-using skill names the console's Results page.** A project's Results shows what each run gave back, newest first, a card each, and it's where a viewer, or someone who only runs the project, opens the console. The skill lists it with the project's pages, names it first on a tour of the console, and answers "where do I see every answer it finished" with it, using the runs list's `agent`, `status` and `since` filters.
