**A project's attaches.** An attach sends the runs a person starts with a key of theirs, limited to one project, to their working copy of the project's code before it's deployed. This adds the routes that write them, and what a runtime builds them on:

- **`PUT`/`DELETE /v1/system/tenants/{tenantId}/projects/{projectId}/attaches/{attachId}` and `PUT …/attaches/{attachId}/index`**, mounted when `createApp` is given `systemAttaches` (`{ binding, routeHostAllowed }`, with `SystemAttachesBinding` for the runtime's store). Only a key holding `system:attaches` itself writes them. Each check names the person and key the body names, never the caller: the route's host is on the operator's list, the key is read in the path's tenant and must be live, the person's and limited to the project, and the person holds `admin` there (`canFor`). The binding then refuses a project in production, someone else's own test project, and an attach written for another person or key. An index copy is checked as a deploy checks a pack's `index.json`, takes no data blocks, and is bounded: at most `ATTACH_INDEX_MAX_BYTES` (1.5 MiB), `ATTACH_INDEX_MAX_PRIMITIVES` (2,000), and one copy every `ATTACH_INDEX_MIN_INTERVAL_MS` (2 s). Ending an attach works for a suspended tenant too. Every write is on record. `createApp` refuses to start with `systemAttaches` but without `tokenAdmin`, `authz`, `systemTenantDirectory` or `systemAccessAudit`, naming each that's missing.
- **The TypeScript client's `systemAttaches`** (`put`, `putIndex`, `end`), with the Python and Java clients' wrappers generated from the same operations.

- **`system:attaches`**, a system scope for writing a project's attaches. Only a key holding it itself uses it (`ownSystemScope`, which the package exports): `kindgi:system` doesn't stand in. No key holds it on a runtime serving one tenant, with or without a pack service per deployment.
- **The key a run came with.** `POST /v1/runs` passes the calling key's id to the run handler as `callerTokenId`, on `InvokeAgentBindingInput` and `InvokeFlowBindingInput`: an API key's, a person's or a service account's, and none for a sign-in session. The body never sets it.
- **`checkPackIndex`**: the deploy route's checks of a pack's `index.json`, on their own and exported, so a runtime checks a copy of an index as a deploy would. A deploy accepts and refuses the same indexes as it did.
- **Error codes:** `attach-ended` (409), which the TypeScript, Python and Java clients list as a conflict; `attach-not-found` (404); `attach-needs-project-admin`, `attach-project-in-production`, `attach-key-not-usable`, `attach-key-not-limited-to-project`, `attach-test-project-not-theirs`, `attach-mismatch` and `attach-route-host-not-allowed` (409), with `attach-ended` naming its `endedReason` on a write; and `attach-index-invalid` (400), `attach-index-too-large` (413) and `attach-index-too-soon` (429). The errors reference has each.
- **`KINDGI_ATTACH_ROUTE_HOSTS`** (env-schema): the hosts an attach's route may be on, with `parseAttachRouteHosts` and `ATTACH_ROUTE_HOSTS_VAR`. It's written as `KINDGI_PACK_ENDPOINT_HOSTS` is, and its errors name it.
