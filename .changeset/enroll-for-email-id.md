`kindgi license enroll --for` says what someone who signs in by email gives it: the `em-` id their key page shows. Its help, its usage line, the message when `--for` is missing, the error for a value that isn't one, and `kindgi license renew`'s pointer to enroll all said a GitHub login only. What `--for` accepts is unchanged: an `em-` id was already accepted.
