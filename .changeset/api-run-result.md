**`@kindgi/api/run-result`: one way to draw a run's result.** A subpath export with no runtime dependencies, so a browser bundle can import it. `RUN_STATUS_WORDS` is a run's status in words (`pending` is "Waiting to start", `completed` is "Done"). `answerValue(run)` is what a run answered: an agent's typed output, else its reply's content; a flow's output. A JSON object or array written as text, bare or in one fence, is read as its value (`answerOfText`). `answerBlocks(answer, limit)` splits an answer into `value`, `text`, `fields` and `records` blocks by its shape alone, marks a block `long` past 1,200 drawn characters, 12 fields or 10 rows, and cuts at `limit` characters, counting every string a block draws, with `truncated`. `RESULT_LIMIT` (100,000) is what the console draws, and `clipText` cuts a text without halving a character. In a chat, a run tool's result carries the answer's blocks, within 8,000 characters, in `_meta["kindgi/blocks"]`, and the run view draws them, folding long ones. Its `structuredContent` and its text keep the answer as one string, and a result without `_meta` shows it as one text. The run view's status line uses the same words, with the time taken.
