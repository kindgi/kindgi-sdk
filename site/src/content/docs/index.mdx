## Start with your coding agent

Paste this prompt into your coding agent: Claude Code, Cursor, Codex or any
other. It takes you from nothing to a first agent that answers. Along the way, you
sign in, copy two values and answer one question.

```text
Set up Kindgi for me: read https://docs.kindgi.com/start/agent.md and follow it step by step. Tell me whenever you need me to do something, and wait for me.
```

## Quickstart

From an empty folder to an agent that answers: you run one command, and your
coding agent does the rest. [Quickstart](start/quickstart/)

**Rather write it yourself?** A first pack by hand, running on your machine in
ten minutes: [TypeScript](start/quickstart-typescript/),
[Python](start/quickstart-python/), [Java](start/quickstart-java/) or
[Scala](start/quickstart-scala/).

## What you need

- **Either Node or Python.** Which one depends on your pack's language:
  - **TypeScript:** Node 22.12 or later.
  - **Python:** Python 3.11 or later, and uv (or Poetry, or pip). The `kindgi`
    CLI comes from PyPI with its own copy of Node.
  - **Java or Scala (preview):** a JDK 17 or later, and Node or uv to run the
    CLI. A Java pack brings Maven; a Scala pack needs sbt.
- **Docker** (Docker Desktop, or the Docker engine on Linux). `kindgi dev`
  runs Kindgi's runtime in it on your machine.
- **Access to the runtime image:** sign in at
  [access.kindgi.com](https://access.kindgi.com) with GitHub, to get the
  image's pull credentials and a free non-production license key, for staging
  and CI.
- **A model:** your model provider's API key, or an open model you serve
  yourself, such as Ollama on your machine, with no key.

[Install](start/install/) has the details, and `kindgi doctor` checks what
Kindgi needs.

## Free on your machine, with support for local models

Everything you build and test on your machine is free: `kindgi dev` runs the
runtime in development mode, which needs no license key. Your agents can run
on a model on your machine too, with no API key and no cost per call.
[Connect a model you serve](guides/models/serve-your-own-model/) shows how,
with Ollama as the example.

Running Kindgi in production needs a commercial license. Check
[Licensing](concepts/licensing/) for more details.
