## Your coding agent already knows Kindgi

`kindgi init` gives your project Kindgi's skills: instructions your coding
agent loads when the task calls for them. Describe what you want in your own
words. The agent writes the code, runs it, reads what happened and fixes it.

<CardGrid>
  <Card title="It knows your version" icon="open-book">
    The skills ship with the CLI, written for the Kindgi version you
    installed. Claude Code loads the one the task needs.
  </Card>
  <Card title="It writes the code" icon="pencil">
    Tools, agents, guardrails and flows, in your project's TypeScript or
    Python.
  </Card>
  <Card title="It runs Kindgi" icon="rocket">
    `kindgi dev` to start Kindgi on your machine, `kindgi runs start` to try
    what it wrote, the run's journal to find what went wrong.
  </Card>
  <Card title="You still decide" icon="comment-alt">
    You name your pack and its agents, and you provide the credentials, such as
    your model provider's API key. The agent never writes them into code.
  </Card>
</CardGrid>
