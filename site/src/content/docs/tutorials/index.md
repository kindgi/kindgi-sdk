Each tutorial builds one working thing from an empty directory. The steps
that need no model are run by our CI against the version of Kindgi these
docs describe, so they work as written; the steps with a real model were run
by hand for this version.

- **Build a support desk** in [TypeScript](support-desk-typescript/) or
  [Python](support-desk-python/): tools over your own code, an agent with a
  typed answer, and a flow that acts on it.
