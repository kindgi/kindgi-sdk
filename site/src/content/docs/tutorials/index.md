A tutorial takes you from an empty directory to one working app, step by
step.

Kindgi's CI runs every step that needs no model against the version of
Kindgi these docs describe, so those steps work as written. The steps that
call a real model were run by hand for this version.

- **Build a support desk** in [TypeScript](support-desk-typescript/) or
  [Python](support-desk-python/): tools over your own code, an agent with a
  typed answer, and a flow that acts on it.
- **[A WooCommerce store's agents on Kindgi Cloud](woocommerce-on-kindgi-cloud/):**
  the store's staff ask and approve in wp-admin, each as themselves, and each
  new order gets a review.
