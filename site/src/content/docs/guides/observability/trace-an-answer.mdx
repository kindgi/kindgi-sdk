This guide reads a turn's provenance record, to see where an answer came
from and what it cost.

Every agent turn leaves a **provenance record**: a graph of the turn, from the
user's message through each model call and tool call to the answer. It names
the model of each call and the version of each tool, and, beside the graph,
each call's tokens and cost.
Use it to answer "where did this answer come from?" and "what did it cost?".

## Before you start

- **A runtime,** such as `kindgi dev`, with Kindgi 0.1's CLI.
- **The id of an agent turn's run.** `kindgi runs list` shows it.
- **`KINDGI_API_URL` and `KINDGI_API_TOKEN`** set in your shell, for the
  HTTP requests. With `kindgi dev`, they're the URL and token it prints. They're
  also in the pack's `.kindgirc.json`.

Read it from the answer backwards:

- The answer, `model-output:2`, was produced by the second model call.
- That call answered the user's message: it's `caused-by` `input:0`.
- It also read the echo tool's result: it's `influenced-by` that
  `tool-result`.
- The tool call that produced the result was `invoked` by the first model
  call.

| Node | What it is |
| --- | --- |
| `input` | The message the turn answered. |
| `model-call` | One call to a model: `modelVersion` is `provider/model`; `attributes` has its `step`, `model`, `providerId`, why it stopped (`finishReason`) and its `callId`. |
| `tool-call`, `tool-result` | A tool the model called, with the exact tool version that ran, and what it returned. |
| `model-output` | The answer. |
| `wait`, `resume` | A tool call that waited for an approval: the wait, and the decision that ended it. |

Edges point from an effect to its cause: `caused-by`, `invoked`, `produced`,
and `influenced-by` from a model call to each tool result it read.

`callUsage` holds each model call's tokens, cost in USD, duration and the
model version that answered, `servedModel`, by the call's `callId`. A token
count the provider reports is there, 0 included, as in `cacheReadTokens: 0`.
One it doesn't report is absent.

A turn that waited for an approval is recorded whole, before and after the
wait. The wait sits between the tool call and its result: the `tool-call`
`waited-on` a `wait` node, which was `resumed-from` a `resume` node, and the
`tool-result` was `caused-by` the `resume`. The `resume` node's `actor` is who
decided, and its `attributes` have the decision, the rationale and the
approval's id. A call a reviewer rejected:

```json
{"id": "tool-hitl-gate-resume:toolu_01MAfC8Fb7e24iY12Cenoh11", "kind": "resume", "timestamp": "2026-10-05T16:26:25.504Z", "actor": "user:26fc414a-b49f-4e1f-a022-162865770178", "attributes": {"gate": "tool-call", "decision": "reject", "rationale": "Not confirmed yet", "approvalId": "12c38101-4cac-4241-8fc7-57323e4f63b9"}}
```

Its `tool-call` is there too, and its `tool-result` is the rejection the model
read.

`kindgi runs get <run-id>` shows the same graph, under `output.provenance`,
without `callUsage`.

## From your app

Read the record in your app's code. Ask your coding agent: "I want to see
which model calls and tool calls produced a run's answer, and what each model
call cost." For reference, the code looks like this. Each script takes the
run's id as its first argument:

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
// trace.ts
import { createClient } from '@kindgi/sdk/client';
import type { RunId } from '@kindgi/sdk/types';

const kindgi = createClient(); // KINDGI_API_URL, KINDGI_API_TOKEN, or the running kindgi dev

const record = await kindgi.provenance.get(process.argv[2] as RunId);
for (const node of record.dag.nodes) {
  const { callId } = (node.attributes ?? {}) as { callId?: string };
  const call = typeof callId === 'string' ? record.callUsage?.[callId] : undefined;
  console.log(node.kind, node.modelVersion ?? '', call ? `${call.usage.promptTokens}+${call.usage.completionTokens} tokens, ${call.costUsd} USD` : '');
}
```

</TabItem>
<TabItem label="Python">

```python
# trace.py
import sys

from kindgi.client import Kindgi

kindgi = Kindgi()  # KINDGI_API_URL, KINDGI_API_TOKEN, or the running kindgi dev

record = kindgi.provenance.get(sys.argv[1])
for node in record.dag.nodes:
    call_id = (node.attributes or {}).get("callId")
    call = (record.call_usage or {}).get(call_id) if call_id else None
    usage = f"{call.usage.prompt_tokens}+{call.usage.completion_tokens} tokens, {call.cost_usd} USD" if call else ""
    print(node.kind, node.model_version or "", usage)
```

</TabItem>
<TabItem label="Java">

```java
// src/main/java/com/acme/app/Trace.java
package com.acme.app;

import com.kindgi.client.Kindgi;
import com.kindgi.client.models.ProvenanceRecord;
import java.util.Map;
import java.util.Objects;
import java.util.UUID;

public final class Trace {
  public static void main(String[] args) {
    Kindgi kindgi = Kindgi.create(); // KINDGI_API_URL, KINDGI_API_TOKEN, or the running kindgi dev

    ProvenanceRecord record = kindgi.provenance().get(UUID.fromString(args[0]));
    Map<String, ProvenanceRecord.CallUsageValue> usage =
        Objects.requireNonNullElse(record.callUsage(), Map.of());
    for (ProvenanceRecord.Dag.NodesItem node : record.dag().nodes()) {
      Object callId = node.attributes() == null ? null : node.attributes().get("callId");
      ProvenanceRecord.CallUsageValue call = callId instanceof String id ? usage.get(id) : null;
      System.out.println(node.kind() + " " + Objects.toString(node.modelVersion(), "") + " "
          + (call == null ? ""
              : call.usage().promptTokens() + "+" + call.usage().completionTokens() + " tokens, "
                  + call.costUsd() + " USD"));
    }
  }
}
```

</TabItem>
<TabItem label="Scala">

```scala
// src/main/scala/acme/app/Trace.scala
package acme.app

import com.kindgi.client.Kindgi
import com.kindgi.client.models.ProvenanceRecord
import java.util.UUID
import scala.jdk.CollectionConverters._

object Trace {
  def main(args: Array[String]): Unit = {
    val kindgi = Kindgi.create() // KINDGI_API_URL, KINDGI_API_TOKEN, or the running kindgi dev

    val record = kindgi.provenance().get(UUID.fromString(args(0)))
    val usage: Map[String, ProvenanceRecord.CallUsageValue] =
      Option(record.callUsage).map(_.asScala.toMap).getOrElse(Map.empty)
    for (node <- record.dag.nodes.asScala) {
      val callId = Option(node.attributes).flatMap(a => Option(a.get("callId"))).collect { case id: String => id }
      val call = callId.flatMap(usage.get)
      val cost = call.map(c => s"${c.usage.promptTokens}+${c.usage.completionTokens} tokens, ${c.costUsd} USD").getOrElse("")
      println(s"${node.kind} ${Option(node.modelVersion).getOrElse("")} $cost")
    }
  }
}
```

## Find records

`kindgi provenance list` lists records, newest first, without their graphs.
`--created-after=<time>` keeps the newer ones, `--run=<run-id>` one run's,
`--agent=<agent-id>` one agent's turns at any version, and `--project=<id>`
or `--org=<id>` one project's or one org's. `--table` prints a row per
record:

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```sh
pnpm exec kindgi provenance list --created-after=2026-10-06T17:00:00Z --limit=3 --table
```

Over HTTP it's `GET /v1/provenance`, filtered by `runId`, `agentId` or
`createdAfter`:

```sh
curl "$KINDGI_API_URL/v1/provenance?createdAfter=2026-10-05T16:25:00Z&limit=3" \
  -H @<(printf 'Authorization: Bearer %s\n' "$KINDGI_API_TOKEN")
```

```json
{"data":[{"id":"e87e13ae-472f-404b-8dfe-94ec738980cd","runId":"f91ff793-b029-48e8-9ce4-f9fa70bd0c40","tenantId":"9126df1e-094b-496d-9ea8-7daab93c3f4f","version":"1.0.0","createdAt":"2026-10-05T16:26:30.533Z","signed":false,"projectId":"13b7cfca-8b77-4983-858f-149c16afe56d"},…]}
```

Each record carries its run's `projectId`. `scopeKind=project&scopeId=<id>`
lists one project's records, and `scopeKind=org&scopeId=<id>` every
project's in an org. The clients call it `scope`. A record with no project is
listed only without a scope, and one whose run doesn't name its agent isn't
matched by `--agent`.

`signed` is `false`: the records themselves aren't signed as they're
written. To hand a run's provenance to someone, export it signed by the
deployment, with `kindgi provenance export <run-id> > provenance.json`.
Check it with `kindgi exports verify provenance.json`, as
[Export signed evidence](../export-signed-evidence/) shows.

has every operation.
