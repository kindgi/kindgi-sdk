This page builds `acme.process-order`: look an order up, have an agent write
a thank-you note, then confirm the order with that note. Two tools, one
agent, one flow.

## The tools

Ask your coding agent: "I want a tool that looks up an order, and one that
confirms an order with a note." Kindgi's skills in your pack tell it how
([How it knows Kindgi](../../../start/coding-agents/)). For reference, the
tools look like this. `acme.get-order` only reads, so it says
`mutating: false`. `acme.confirm-order` changes something, so it doesn't:

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
// tools/get-order/index.ts
import { defineTool } from '@kindgi/sdk/define';
import type { ToolId } from '@kindgi/sdk/types';
import { z } from 'zod';

const Order = z.object({
  orderId: z.string(),
  customer: z.string(),
  total: z.number(),
  items: z.array(z.object({ sku: z.string(), quantity: z.number().int() })),
});

const ORDERS: Record<string, z.infer<typeof Order>> = {
  'A-100': { orderId: 'A-100', customer: 'ada@example.com', total: 42.5, items: [{ sku: 'mug', quantity: 2 }] },
  'A-200': {
    orderId: 'A-200',
    customer: 'grace@example.com',
    total: 1250,
    items: [
      { sku: 'desk', quantity: 1 },
      { sku: 'lamp', quantity: 2 },
    ],
  },
};

const defined = defineTool({
  id: 'acme.get-order' as ToolId,
  description: 'Looks up an order by id.',
  version: '0.1.0',
  input: z.object({ orderId: z.string().min(1) }),
  output: Order,
  effects: [],
  mutating: false, // only reads
  handler: async ({ orderId }) => {
    const order = ORDERS[orderId];
    if (order === undefined) throw new Error(`No order ${orderId}`);
    return order;
  },
});

if (defined.kind === 'err') throw new Error(defined.error.message);

export default defined.value;
```

```ts
// tools/confirm-order/index.ts
import { defineTool } from '@kindgi/sdk/define';
import type { ToolId } from '@kindgi/sdk/types';
import { z } from 'zod';

const defined = defineTool({
  id: 'acme.confirm-order' as ToolId,
  description: 'Confirms an order and emails the customer.',
  version: '0.1.0',
  input: z.object({ orderId: z.string(), note: z.string().optional() }),
  output: z.object({
    orderId: z.string(),
    status: z.literal('confirmed'),
    note: z.string().optional(),
  }),
  effects: [],
  // no `mutating: false`: it changes something
  handler: async ({ orderId, note }) => ({ orderId, status: 'confirmed' as const, note }),
});

if (defined.kind === 'err') throw new Error(defined.error.message);

export default defined.value;
```

```python
# tools/get_order.py
from pydantic import BaseModel, Field

from kindgi import tool


class OrderQuery(BaseModel):
    order_id: str = Field(alias="orderId", min_length=1)


class Item(BaseModel):
    sku: str
    quantity: int


class Order(BaseModel):
    order_id: str = Field(alias="orderId")
    customer: str
    total: float
    items: list[Item]


ORDERS = {
    "A-100": {"customer": "ada@example.com", "total": 42.5, "items": [{"sku": "mug", "quantity": 2}]},
    "A-200": {
        "customer": "grace@example.com",
        "total": 1250,
        "items": [{"sku": "desk", "quantity": 1}, {"sku": "lamp", "quantity": 2}],
    },
}


@tool(id="acme.get-order", mutating=False)  # only reads
def get_order(input: OrderQuery) -> Order:
    """Looks up an order by id."""
    order = ORDERS.get(input.order_id)
    if order is None:
        raise ValueError(f"No order {input.order_id}")
    return Order(orderId=input.order_id, **order)
```

```python
# tools/confirm_order.py
from typing import Literal

from pydantic import BaseModel, Field

from kindgi import tool


class ConfirmInput(BaseModel):
    order_id: str = Field(alias="orderId")
    note: str | None = None


class Confirmed(BaseModel):
    order_id: str = Field(alias="orderId")
    status: Literal["confirmed"] = "confirmed"
    note: str | None = None


@tool(id="acme.confirm-order")  # no mutating=False: it changes something
def confirm_order(input: ConfirmInput) -> Confirmed:
    """Confirms an order and emails the customer."""
    return Confirmed(orderId=input.order_id, note=input.note)
```

```java
// src/main/java/acme/tools/GetOrder.java
package acme.tools;

import com.kindgi.pack.Tool;
import jakarta.validation.constraints.Size;
import java.util.List;
import java.util.Map;

public final class GetOrder {
  public record Input(@Size(min = 1) String orderId) {}

  public record Item(String sku, int quantity) {}

  public record Order(String orderId, String customer, double total, List<Item> items) {}

  private static final Map<String, Order> ORDERS = Map.of(
      "A-100", new Order("A-100", "ada@example.com", 42.5, List.of(new Item("mug", 2))),
      "A-200", new Order("A-200", "grace@example.com", 1250,
          List.of(new Item("desk", 1), new Item("lamp", 2))));

  public static final Tool<Input, Order> TOOL = Tool.define("acme.get-order")
      .description("Looks up an order by id.")
      .version("0.1.0")
      .input(Input.class)
      .output(Order.class)
      .mutating(false) // only reads
      .handler((input, ctx) -> {
        Order order = ORDERS.get(input.orderId());
        if (order == null) throw new IllegalArgumentException("No order " + input.orderId());
        return order;
      });

  private GetOrder() {}
}
```

```java
package acme.tools;

import com.fasterxml.jackson.annotation.JsonProperty;
import com.kindgi.pack.Tool;
import org.jspecify.annotations.Nullable;

public final class ConfirmOrder {
  public record Input(String orderId, @Nullable String note) {}

  public enum Status {
    @JsonProperty("confirmed") CONFIRMED
  }

  public record Confirmed(String orderId, Status status, @Nullable String note) {}

  public static final Tool<Input, Confirmed> TOOL = Tool.define("acme.confirm-order")
      .description("Confirms an order and emails the customer.")
      .version("0.1.0")
      .input(Input.class)
      .output(Confirmed.class)
      // no mutating(false): it changes something

  private ConfirmOrder() {}
}
```

```scala
package acme.tools

import com.kindgi.pack.scaladsl._
import jakarta.validation.constraints.Size

object GetOrder {
  final case class Input(@Size(min = 1) orderId: String)
  final case class Item(sku: String, quantity: Int)
  final case class Order(orderId: String, customer: String, total: Double, items: Seq[Item])

  private val orders = Map(
    "A-100" -> Order("A-100", "ada@example.com", 42.5, Seq(Item("mug", 2))),
    "A-200" -> Order("A-200", "grace@example.com", 1250, Seq(Item("desk", 1), Item("lamp", 2))))

  val tool: Tool[Input, Order] = Tool[Input, Order]("acme.get-order")
    .description("Looks up an order by id.")
    .version("0.1.0")
    .readOnly // only reads
    .handler((in, _) =>
      orders.getOrElse(in.orderId, throw new NoSuchElementException(s"No order ${in.orderId}")))
}
```

## The agent

Ask your coding agent: "I want an agent that writes a one-sentence thank-you
note for an order." For reference, the agent looks like this. It has no tools:
it reads the order's customer and total from its input and answers with one
sentence:

<Tabs syncKey="lang">


## The flow

Ask your coding agent: "I want a flow that looks up an order, has the agent
write a thank-you note, then confirms the order with that note." For
reference, the flow looks like this:

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
// flows/process-order/index.ts
import { defineFlow } from '@kindgi/sdk/define';

const defined = defineFlow({
  id: 'acme.process-order',
  version: '0.1.0',
  name: 'Process an order',
  description: 'Looks up an order, writes a thank-you note, and confirms the order with it.',
  nodes: [
    {
      id: 'order',
      kind: 'tool',
      ref: 'acme.get-order',
      inputMapping: { orderId: { path: 'runInput.orderId' } },
    },
    {
      id: 'note',
      kind: 'agent',
      ref: 'acme.note-writer',
      inputMapping: {
        customer: { path: 'nodeOutputs.order.customer' },
        total: { path: 'nodeOutputs.order.total' },
      },
    },
    {
      id: 'confirm',
      kind: 'tool',
      ref: 'acme.confirm-order',
      inputMapping: {
        orderId: { path: 'runInput.orderId' },
        note: { path: 'nodeOutputs.note.text' },
      },
    },
  ],
  edges: [
    { id: 'e1', from: '$start', to: 'order' },
    { id: 'e2', from: 'order', to: 'note' },
    { id: 'e3', from: 'note', to: 'confirm' },
    { id: 'e4', from: 'confirm', to: '$end' },
  ],
});

if (defined.kind === 'err') throw new Error(defined.error.message);

export default defined.value;
```

```java
// src/main/java/acme/flows/ProcessOrder.java
package acme.flows;

import acme.agents.NoteWriter;
import acme.tools.ConfirmOrder;
import acme.tools.GetOrder;
import com.kindgi.pack.Flow;
import java.util.Map;

public final class ProcessOrder {
  public static final Flow FLOW = Flow.define("acme.process-order")
      .version("0.1.0")
      .set("name", "Process an order")
      .set("description", "Looks up an order, writes a thank-you note, and confirms the order with it.")
      .node(Map.of(
          "id", "order",
          "kind", "tool",
          "ref", GetOrder.TOOL,
          "inputMapping", Map.of("orderId", Map.of("path", "runInput.orderId"))))
      .node(Map.of(
          "id", "note",
          "kind", "agent",
          "ref", NoteWriter.AGENT,
          "inputMapping", Map.of(
              "customer", Map.of("path", "nodeOutputs.order.customer"),
              "total", Map.of("path", "nodeOutputs.order.total"))))
      .node(Map.of(
          "id", "confirm",
          "kind", "tool",
          "ref", ConfirmOrder.TOOL,
          "inputMapping", Map.of(
              "orderId", Map.of("path", "runInput.orderId"),
              "note", Map.of("path", "nodeOutputs.note.text"))))
      .edge("e1", "$start", "order")
      .edge("e2", "order", "note")
      .edge("e3", "note", "confirm")
      .edge("e4", "confirm", "$end")
      .build();

  private ProcessOrder() {}
}
```

A step with no `inputMapping` can be shorter: `.toolNode("order", GetOrder.TOOL)`
or `.agentNode("note", NoteWriter.AGENT)`.

```scala
// src/main/scala/acme/flows/ProcessOrder.scala
package acme.flows

import acme.agents.NoteWriter
import acme.tools.{ConfirmOrder, GetOrder}
import com.kindgi.pack.scaladsl._

object ProcessOrder {
  val flow: Flow = Flow("acme.process-order")
    .version("0.1.0")
    .set("name", "Process an order")
    .set("description", "Looks up an order, writes a thank-you note, and confirms the order with it.")
    .node(Map(
      "id" -> "order",
      "kind" -> "tool",
      "ref" -> GetOrder.tool,
      "inputMapping" -> Map("orderId" -> Map("path" -> "runInput.orderId"))))
    .node(Map(
      "id" -> "note",
      "kind" -> "agent",
      "ref" -> NoteWriter.agent,
      "inputMapping" -> Map(
        "customer" -> Map("path" -> "nodeOutputs.order.customer"),
        "total" -> Map("path" -> "nodeOutputs.order.total"))))
    .node(Map(
      "id" -> "confirm",
      "kind" -> "tool",
      "ref" -> ConfirmOrder.tool,
      "inputMapping" -> Map(
        "orderId" -> Map("path" -> "runInput.orderId"),
        "note" -> Map("path" -> "nodeOutputs.note.text"))))
    .edge("e1", "$start", "order")
    .edge("e2", "order", "note")
    .edge("e3", "note", "confirm")
    .edge("e4", "confirm", "$end")
    .build()
}
```

- **`nodes`** are the steps. Each has an `id` (unique in the flow), a `kind`
  and a `ref`: the id of the tool or agent it runs. In Python, Java and Scala,
  `ref` can also be the tool or agent itself.
- **`edges`** connect them. `$start` and `$end` are where the run enters and
  leaves; an edge without a condition fires when its source step completes.
- **`inputMapping`** builds each step's input from the run's input
  (`runInput.…`) and earlier steps' outputs (`nodeOutputs.<step>.…`). See
  [Pass data between steps](../pass-data-between-steps/).

The shape is checked when the file loads: ids, edges between steps that
exist, `$start` and `$end`, no cycles. That the tools and the agent exist is
checked when a run starts: a run of a flow that names a tool your tenant
doesn't have is refused before anything runs.

## The agent step

An agent step runs one turn of the agent, as a run of its own (a child of the
flow's run). The agent gets the step's input twice: as structured input, which
`{{ input.customer }}` in its instructions reads, and as its user message (the
input as JSON). [Give an agent its input](../../agents/give-an-agent-input/)
has the details.

The step's output has the answer as `text`, and as `output` when the agent
declares a typed answer, plus the turn's `runId`. Without a model provider,
`dev-echo` answers, and the note is the agent's input echoed back.

## Change it

Save a file and `kindgi dev` loads the new version; the next run uses it, with
no restart. A run already in flight keeps the version it started on. Change
`version` when what callers send or get back changes, not on every save.
