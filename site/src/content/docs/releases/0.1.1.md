The SDK and CLI release 0.1.1.

## New

- `init` adds `zod`, and, in a pnpm app, `allowBuilds: { esbuild: false }` in `pnpm-workspace.yaml`.

## Fixed

- In 0.1.0, `init` from npm wrote no `.gitignore`, so git would track `.env` (where your model key goes) and `.kindgirc.json` (the dev token).
- In a pnpm 11+ app, the first `pnpm install` stopped with `ERR_PNPM_IGNORED_BUILDS` for `esbuild`.
- `init` didn't add Zod, which tools and agents use for their schemas.

## Changed

- The runtime's database user no longer needs to be a superuser: `CREATEROLE` and owning the runtime's database are enough.
