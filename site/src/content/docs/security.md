---
title: Report a security issue
description: How to report a security vulnerability in Kindgi privately, and what happens next.
---

Report a security vulnerability privately, by email to
[contact@kindgi.com](mailto:contact@kindgi.com), with "Security" in the
subject. Don't report a suspected vulnerability anywhere public.

Include what you can:

- the affected packages and their versions;
- a description of the issue and its impact;
- steps, or a proof of concept, that reproduce it.

We acknowledge the report, keep you informed while we investigate, and
credit you in the [release notes](../releases/) unless you prefer
otherwise.

## Supported versions

Kindgi SDK packages are in preview (`0.x`). Security fixes land on the
latest release only.
